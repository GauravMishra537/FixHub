# FixHub Frontend

React application with TypeScript, Vite, and Tailwind CSS.

## Setup

See [../docs/setup/startup-guide.md](../docs/setup/startup-guide.md) for complete instructions.

## Build and Run

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Run tests
npm run test

# Type check
npx tsc --noEmit
```

## Configuration

Frontend configuration uses `VITE_`-prefixed environment variables. See [../docs/setup/environment-variables.md](../docs/setup/environment-variables.md).
